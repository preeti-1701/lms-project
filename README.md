Project Overview

The Learning Management System (LMS) is a web-based application developed to manage online learning activities efficiently. The system allows administrators, teachers, and students to interact through a centralized platform. It helps in course management, student enrollment, assignment submission, attendance tracking, and communication between teachers and students.

This project is designed using Python and the Django framework to provide a secure, scalable, and user-friendly educational platform.

Features
Admin Module

Manage students and teachers
Add, update, and delete courses
Monitor system activities
Manage user authentication and permissions

Teacher Module

Create and manage courses
Upload study materials
Post assignments and quizzes
Track student performance and attendance

Student Module
Register and log in securely
Enroll in courses
Access learning materials
Submit assignments
View grades and attendance
