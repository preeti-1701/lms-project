LMS Project: A full-stack Learning Management System (LMS) project built using React, Node.js, Express.js, and PostgreSQL.

Features:
- User Authentication using JWT
- Admin Login
- Course Management
- Video Management
- Protected Routes
- PostgreSQL Database Integration
- REST API Backend

Tech Stack
Frontend:
- React.js
- Axios
- React Router DOM

Backend:
- Node.js
- Express.js
- PostgreSQL
- JWT Authentication
- bcrypt


Setup Instructions: Backend Setup -
```bash
cd backend
npm install
npm run dev
